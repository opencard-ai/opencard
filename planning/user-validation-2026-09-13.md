# User validation and measurement plan — 2026-09-13

Owner: Kacey. Status: materials ready; participant recruitment pending. No outreach sent.

## Two observed tasks (15 minutes, 5–10 participants)
Start with US credit-card holders; Chinese-speaking US users are a hypothesis, not an established segment. Do not request card numbers, account screenshots, income documents or passwords.

1. Think of your next card decision. Open the homepage, find 2–3 candidates, compare them, explain the fee/trade-off, and locate issuer terms. Do not submit an application.
2. Add a card you already own, identify a benefit you can realistically use, and record a practice use. Explain what remains and when it resets. Remove practice data afterwards if desired.

Record task completion, time, help needed, wrong turns, confusing terms and stated confidence. Ask “What would you do next without this site?” and “What would make you return?” rather than “Do you like it?”

## Success and stop rules
- Discovery sample is qualitative, not a statistically powered experiment.
- Fix repeat blockers seen in 2+ sessions before paid acquisition.
- Separate inability to find a control from incorrect benefit data.
- Never equate issuer outbound clicks with approved applications.
- Compare consented wizard completion/selection starts, first benefit use/first card adds, and elapsed-day 7/30 My Cards return events/cohort starts. See funnel-measurement.md for event limitations.
- Start retention observation only after deployment and verified consented event collection. Calendar earliest checkpoints: 2026-09-20 and 2026-10-13 if measurement begins 9/13; actual baseline may be later.
